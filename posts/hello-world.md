## Tại sao lại tạo blog này?

Blog này được thiết kế để:
- **Lưu trữ kiến thức**: Ghi chú lại những gì tôi học được.
- **Chia sẻ ý tưởng**: Nơi tôi viết ra những suy nghĩ của mình.
- **Truy cập dễ dàng**: Vì là web tĩnh, nó load rất nhanh và có thể xem trên mọi thiết bị.

### Đoạn code ví dụ

```javascript
// app.js
function sayHello() {
    console.log("Hello World from MyBlog!");
}
sayHello();
```
